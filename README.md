# djz-idle-vibe-tycoon

An idle tycoon game themed around AI-assisted software development. Click to write code, automate your workflow, deliver apps, and prestige your way to coding empire status. Built with TypeScript, React, Vite, and Tailwind CSS.

## Features

- **Idle / Incremental Gameplay** -- earn code points passively through automations or actively through clicking
- **Developer Theme** -- simulated terminal output, file system tree, and project delivery mechanics
- **Automation System** -- purchase and upgrade automated code generators that produce points per second
- **Prestige Mechanic** -- deliver apps to reset progress with a permanent multiplier
- **Procedural Content** -- dynamically generated project names and terminal messages
- **Upgrade Tree** -- invest code points in upgrades that boost click power and automation output
- **Terminal UI** -- retro-styled command-line interface with color-coded output

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
npm run dev
```

The game runs locally at `http://localhost:5173`.

## Tech Stack

- TypeScript
- React 18
- Vite
- Tailwind CSS
- Zustand (state management)

## How to Play

1. Click action buttons to generate code points and progress
2. Purchase automations to generate code points passively
3. Fill the progress bar to deliver an app and level up
4. Buy upgrades to increase your output
5. Prestige to reset with a permanent multiplier when ready
